# 브라우저 검증

2026-10-23, Codex 내장 Chromium, 로컬 정적 서버에서 확인했습니다.

- Pyodide 0.27.7을 로드하고 배포용 `engine.json`의 Python 모듈을 실제로 실행.
- 업무형 DOCX 샘플 분석: 문단 22개, 표 1개, 셀 12개와 진단을 표시.
- 원문 근거 버튼에서 XML 파트·구조 경로·블록 ID·파일 SHA-256 표시 확인.
- 업무형 XLSX 샘플 분석: 선행 0 `02139`, ISO 날짜, `25%` 표시, 계산하지 않은 수식·캐시 경고 확인.

웹의 분석 시간 표시는 엔진 준비 이후의 브라우저 워커 내부 처리 시간입니다. 다운로드·초기화는 포함하지 않습니다. 비교 리포트는 로컬 CPython·Node 측정값을 사용하며 브라우저 성능과 구분합니다.

전체 브라우저·기기, 모든 파일 크기, 모든 포맷 변형을 보장하는 검증은 아닙니다.
